## Done summary
Built the dictation session and the event stream. dettivo-session (new crate) holds the state machine (idle, recording, transcribing, inserting, idle, with cancelled and failed exits): start takes the single session slot under a lock before the source opens, so concurrent starts leave exactly one winner; a worker thread drains the audio source (a PipeWire capture, the DETTIVO_MOCK_MIC fixture, or a channel in tests), writes the take through TakeWriter, meters levels to the publisher, ends the session recoverably when the device is lost or the default moves, stops itself at the maximum duration, transcribes through the SttEngine frozen at start (a near-silent take never reaches the engine), applies the raw pipeline (whole-word case-insensitive replacements, spoken punctuation, whitespace and sentence capitals; golden tests), hands the text to an Inserter (ClipboardOnly over wl-clipboard-rs until S-08) and keeps the transcript as the last result plus transcript.json in the session directory; the take is discarded unless audio retention is on. cancel works in every state and cancels the engine request; stop reports Failed and Cancelled outcomes as such.

The daemon adds an EventBus (subscriptions per connection with topics, a 256-line channel per connection plus a 16 KB socket send buffer, events.notify lines written by the connection task, events.overflow with the drop count delivered as soon as the channel has room, subscriptions dropped on disconnect) and publishers: the session (dictation.state with job_id, state, previous_state, reason; audio.level from the capture), and the supervisor's new transition hook (engine.state: spawned, loaded, unloaded, crashed, degraded). dictation.start, stop, cancel and status answer with the contract shapes; dictation.reinsert_last is a Linux addition with fixtures and a deltas row; events.subscribe and events.unsubscribe are wired to the connection; system.health reports recording_state dictation and one active job while a session runs. The policy freezes provider and model from [speech], language and mode from the request or [dictation], vocabulary, replacements, spoken punctuation, maximum duration, silence threshold and audio retention, with a config hash for log correlation; a missing model answers NOT_FOUND naming it and the dettivo speech download command; deterministic_polish and enhanced answer NOT_IMPLEMENTED. dettivo dictation start|stop|cancel|status|toggle|reinsert-last and dettivo events --follow [--topic ...] [--count N] (a streaming client that subscribes and prints one JSON line per notification) join the CLI; [dictation] joins the schema, the default file, docs/config.md and the print_default fixture; docs/dictation.md is the document.
