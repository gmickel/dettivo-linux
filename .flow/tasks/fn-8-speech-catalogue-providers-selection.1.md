## Done summary
Built the speech catalogue and model layer. dettivo-speech gains a versioned catalogue compiled into the crate (catalogue/v1.toml: every Whisper model, the Silero VAD model and the Parakeet placeholders, each with provider, id, display name, size, source URL, SHA-256 from the source repositories' LFS pointers, license, redistribution note, languages, quantization, default and availability; a validation test rejects a missing field, a bad checksum, a host off the allowlist or a provider without exactly one default), the on-disk store (ModelStore: <models>/<provider>/<id>/<file> beside manifest.json recording the verified checksum, size, time, catalogue version; readiness ready, unverified, downloading, partial, missing, quarantined; verify() hashes and quarantines a mismatch under <models>/quarantine/<provider>/<id>/<time>/; verify_all() for start; delete), the downloader (one thread per download, reqwest with rustls, a .part file plus a .part.json sidecar that resumes with a Range request for the same URL and restarts when the server ignores ranges, progress at most four times a second, cancellation keeping the partial file, hashing when the last byte lands with quarantine on a mismatch and a verified manifest on a match) and a std-only fixture server (fixture_server.rs) that serves a directory with Range support and can truncate, corrupt or ignore ranges, used by this crate's tests and the daemon's.

The daemon holds a Models service: the store from [paths] models_dir and [models] catalogue_file (a custom catalogue for mirrors and tests, loopback HTTP allowed), downloads bounded by max_concurrent_downloads with a queue, one readiness source for every caller, verification at start off the request path (verify_on_start), and model.download payloads collected for the event stream (the reaper tick logs finished downloads until S-07 delivers the bus). speech.providers.list, speech.selection.get and speech.selection.set answer with the Windows-adopted shapes; selection.set validates provider, model, meeting_model and parakeet_model_id against the catalogue (unknown or unavailable models and cloud ids are INVALID_PARAMS naming them), writes the [speech] keys through the config layer with comments kept, reloads, and the supervisor spec's preload runs from model_selection when the file exists. The Linux additions speech.models.status, download, cancel and delete are in the catalog, the fixtures and the deltas table; delete refuses the selected model with CONFLICT unless force. dettivo speech providers|selection get|set|download [--wait]|cancel|delete [--force]|status [--follow] map to them and dettivo doctor prints a models row. [speech] meeting_model and parakeet_model_id and the [models] section join the schema, the default file, docs/config.md and the print_default fixture; docs/models.md is the document, linked from the README, docs/daemon.md and docs/engines.md.
