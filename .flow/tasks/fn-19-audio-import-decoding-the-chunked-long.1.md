## Done summary
Audio import is real for long audio, and the offline half of the meeting pipeline is in place. `dettivo history import call.m4a` turns a file of any length up to four hours, in any FR-S6 content type, into one history item with its segments, a progress line per chunk while it runs, and no `ffmpeg` on the machine.

`crates/dettivo-audio/src/decode.rs` decodes every content type in-process through Symphonia (`wav`, `aiff`, `caf`, `isomp4`, `aac`, `alac`, `mp3`, `flac`, `ogg`, `vorbis`, `pcm`) and resamples to 16 kHz mono through a windowed-sinc `rubato` resampler packet by packet, so an hour of audio never sits in memory whole; the declared content type picks the probe hint and the containers it may turn out to be, and a file that is something else is refused naming both. `crates/dettivo-transcribe` is the new pipeline crate: the chunker plans 300 s windows overlapping by 2 s with the cut moved to the quietest 50 ms inside the last 5 s (the macOS `ChunkedTranscriptionConfig` values), the merger reconciles consecutive chunks by timestamp (the later chunk's words win from the overlap midpoint, a repeat within 250 ms of a kept word is dropped, a seam run the earlier tail already said is dropped once, boundaries snap to the words that remain, synthetic words for a segment-only engine never leave), the filters are the macOS `MeetingTranscriptHallucinationFilter` lists and the 0.0065 RMS `speechActivationFloor` verbatim, and the job drives chunks through the engine with `recognize`, publishes `job.progress` per chunk, retries a crashed engine once, fails naming the chunk index while keeping earlier text, and cancels between chunks.

The daemon runs imports and re-runs through that job in its own thread (`crates/dettivod/src/jobs_run.rs`), stores segments and words on the item through migration `0002-segments`, keeps the decoded 16 kHz WAV as the retained audio when `[history] keep_audio` is on, refuses a file over `[history] max_import_seconds` (14400) after the probe, and adds `transcripts.cancel` as a registered Linux delta. The CLI gains `history import <file> [--provider --model --language --no-wait]` following `job.progress` on stderr and `history get <id> --words`. `[transcribe]` (chunk, overlap, margin, silence floor, filler filter) and `[history] max_import_seconds` join the schema, the default file, `print_default.json` and `docs/config.md`. `dettivo-qa pipeline import-merge` runs the clip four times through the engine's own command line and compares the merge with a golden, in CI; the MCP harness's `import_audio` step now imports the fixture clip live in both framings. `docs/history.md` gains the import section, `docs/api/linux-deltas.md` the `job.progress` fields and `transcripts.cancel`, and ADR 0022 records the decoder and the merger's rules.
