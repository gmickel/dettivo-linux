Baseline resolution per entry: the approved render `baselines/<surface>/<state>.<theme>.<scale>x.png`, else the Black Gold artboard crop for the black-gold theme, else `first-approval` with the exact approve command and a failing run; a missing crop, a missing fixture file and an unbuilt binary fail by name. `dettivo-qa visual approve <surface> [--state --theme --scale]` renders fresh, refuses a render the style check named, copies it into place and appends date, surface, state, theme, scale, file, approver (git user.name) and the artboard score to docs/design/baselines.md. `dettivo-qa visual --canary` renders the sheet with DETTIVO_QA_CANARY=1 (the theme, under QA mode only, moves the accent to the cursor colour and raises the base and heading sizes by 8 and the spacing units by 3 and 5) and passes only when every diff fails.
