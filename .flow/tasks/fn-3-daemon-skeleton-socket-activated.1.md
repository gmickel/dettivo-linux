## Done summary
Built the resident core: dettivod acquires its socket from systemd activation (LISTEN_FDS) or binds it itself with the runtime directory at 0700 and the socket at 0600, checks SO_PEERCRED on every connection and refuses another uid with UNAUTHORIZED_CLIENT, requires the shared token per request in peer_token mode (DETTIVO_IPC_TOKEN, then the Secret Service via secret-tool, then a 0600 token file, the macOS order with the Keychain replaced), reports the mode in system.capabilities, routes JSON-RPC lines through the contract catalog to system.ping/health/version/capabilities and the six new config.* methods, answers every other catalog method NOT_IMPLEMENTED in the reserved shape and unknown names INVALID_PARAMS, rejects a malformed line with INVALID_PARAMS and an oversized line (ipc.max_line_bytes) without dropping the connection, refuses a second start with exit 1 naming the running pid and socket, unlinks a stale socket file, records its start in state.toml only, watches config.toml and reloads it on change, and shuts down on SIGTERM within daemon.shutdown_timeout_ms releasing the socket and pid file.

dettivo-core owns paths (XDG plus DETTIVO_CONFIG, DETTIVO_DATA_DIR, DETTIVO_IPC_SOCKET, DETTIVO_QA), the typed config schema with a commented DEFAULT_TOML checked against the defaults, loading with per-key sources (default, file, environment), validation that names the key and the line (syntax, unknown key, wrong type, unknown variant), comment-preserving set/unset through toml_edit with type coercion of typed-as-string values and a refusal to write anything the schema would not read back, atomic writes, and the state file.

The dettivo command maps every method 1:1 (status ping/health/version/capabilities, config get/set/unset/path/edit/validate/print-default, call <method> [params]), adds doctor (socket, systemd units, daemon version and health, config validity, platform block, env overrides), honours --socket/--token/--token-file/--timeout-ms/--json/--quiet, and returns the contract exit codes (2 unreachable naming dettivod.socket, 3 refused, 4 bad arguments or INVALID_PARAMS, 5 timeout). systemd user units, scripts/install-user-units.sh (drop-in ExecStart for a checkout) and scripts/qa-activation.sh (measures activation) ship with just install-units / qa-activation and are packaged under usr/lib/systemd/user.

The contract crate gains config.get/set/unset/validate/path/print_default as Linux additions with a config capability block, eight fixtures (print_default carries the real default file), and the deltas additions row; the two INVALID_PARAMS fixture messages now match what the daemon emits.
