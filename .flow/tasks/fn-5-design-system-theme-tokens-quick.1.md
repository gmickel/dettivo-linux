## Done summary
Built the Dettivo design system so every surface looks like part of the desktop it runs on: a C++ theme backend that reads the active Omarchy theme's colors.toml and shell.toml, watches them and re-resolves within 100 ms on a swap, follows the portal colour scheme and reduced-motion preference elsewhere, and falls back to built-in dark and light palettes designed to the same roles; the Theme singleton deriving semantic roles, the type scale, the spacing scale, control geometry and the shell's per-state alphas; the Motion singleton with the named durations, cubic-bezier easings, the pill spring and Motion.duration() that collapses under reduced motion; the DettivoStyle Qt Quick Controls module covering Button (with highlighted and danger variants), TextField, ComboBox, CheckBox, RadioButton, Switch, ScrollBar, Menu, MenuItem, Popup, ToolTip, ItemDelegate, TabBar, TabButton and ProgressBar, selected by every host before its engine exists with a startup assertion that refuses any other style; the shared components SectionLabel, Chip, KeyCap, StatusDot, LevelMeter, Waveform, SegmentedControl, KeyValueRow, ListRow with the selection rail, and Icon; a 22-icon SVG set on the 16 px grid with a 1.5 px stroke and square caps, recoloured by token at runtime, the six-bar mark and the scalable desktop icon; three lints (token literals, icon grid, accessible names against a documented list) wired into just lint-qml and CI; Qt Quick Tests for every component and control plus QTest coverage of the backend; and dettivo-sheet, a host that renders the whole system at 1280 by 1700 and writes a PNG for comparison with docs/design/studio/baselines/design-system.png.

Reviewed and reworked the partial output of an earlier stopped run: kept the toml++ backend structure, the QTest approach and most control files after checking them against the shell tokens and the Studio sheet; rewrote the tokens to the design values (roles at the sheet's alphas, the 2 to 48 spacing scale, control height 28, type scale from the base size), the motion library to the sheet's curves and durations, Chip to the tracked-caps square tag, ListRow to the 18 percent fill with the 2 px rail, SegmentedControl to the inset selected border, Button with the primary and danger variants, the switch track, and the icon set to the sheet's sixteen glyphs with square caps; moved the style into its own DettivoStyle QML module so Qt resolves it by name; added reduced motion and live colour-scheme updates from the portal, LevelMeter, Waveform, the accessible-name list and lint, the Quick Test suite and the sheet host.
