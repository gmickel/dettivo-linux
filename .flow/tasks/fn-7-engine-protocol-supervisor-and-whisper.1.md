## Done summary
Built the engine layer. dettivo-engine-proto frames every message on an engine's stdin and stdout (big-endian u32 header length, JSON header with v, id, kind, name, payload and attachment descriptors, then the attachment bytes) and types the requests (load, unload, recognize, generate, diarize, cancel, status), responses and events (progress, partial, loaded, error); nineteen fixtures under crates/dettivo-engine-proto/fixtures round-trip byte for byte, and a malformed frame is rejected naming the field. dettivo-speech holds the SttEngine trait (the macOS capability contract plus preload, recognize, cancel and backend), EngineProcess (a child over stdio with a bounded stderr tail for crash reports), the Supervisor (spawn on first use, load, keep warm, unload and terminate after the idle timeout, restart with 1/2/4/8 s backoff after a crash, degraded after three consecutive crashes until a load succeeds, a missing binary named with the directories searched) and the coalescing Preloader (startup, model_selection and session_start share one load; a failure is logged privacy-safe and never fails the caller). dettivo-engine-whisper wraps whisper.cpp through whisper-rs with an optional vulkan feature, chooses the backend at load and reports it with a reason, runs as a CLI on a WAV file (--wav --model --json, --language, --prompt, --vad-model, --cpu) and as the protocol server; DETTIVO_FORCE_CPU=1 or --cpu forces the CPU. An English-only model reports en instead of whisper's meaningless detection.

The daemon builds the supervisor from [engines] (directory, stt_idle_seconds, llm_idle_seconds) and [speech] (provider, model), preloads the selected model at start and after a change to [speech] model when the file exists, applies a new idle timeout and directory on reload without a restart, reaps idle engines every 30 s, terminates engines at shutdown, and answers the new Linux method speech.engines (binary, path, running, model, backend, reason, crashes, degraded per known engine). dettivo speech engines prints it and dettivo doctor prints one engine row per binary and exits 1 while an engine is degraded. scripts/models/fetch-test-model.sh fetches whisper/tiny.en and the jfk.wav fixture with pinned checksums; CI caches them and builds the Vulkan feature in unit-rust (vulkan-icd-loader joins the toolchain packages).
