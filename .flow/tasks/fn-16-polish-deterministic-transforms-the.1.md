## Done summary
Built the Polish layers, the Enhanced provider layer and the `polish.*` API. `crates/dettivo-language` is now the text crate: `raw` (the replacement table, spoken punctuation and whitespace discipline, moved out of `dettivo-session`), `polish` (the macOS `LocalPolishFallback` transforms, the styles and the whole `PostProcessors` pipeline), `policy` (the `PolishRulesConfig` schema version 1, the macOS resolution order — user app profile, built-in mapping, app class, global — the terminal prose heuristics, and the eight-character SHA-256 policy hash), `enhanced` (the prompt profile with its unspoofable transcript markers, the output guard, the no-op guard, the thinking-block stripper, the rewrite guard that keeps short text away from the model, the repair pass and the fallback routing) and `provider` (the `LlmProvider` trait with `ollama`, `openai_compatible`, the `local` stub, the `DETTIVO_MOCK_LLM` mock and the endpoint trust gate). `pipeline::run` is the one entry point the session and `polish.test` both call, so a sample and a dictation cannot disagree.

The macOS suites are checked in as data under `crates/dettivo-language/tests/goldens/` (96 cases across `polish_fallback.json` 18, `post_processors.json` 37, `at_prefix.json` 35, `warp_regressions.json` 6) and drive the tests verbatim; a difference from macOS fails with the case's name.

On the wire: `dictation.start` accepts `raw`, `deterministic_polish` and `enhanced` (`polish` is the contract's alias for the second); the completion `dictation.state`, `transcripts.get` and the history item carry `mode`, `notice` (`kind`, `reason`) and `policy_hash`; `system.capabilities` gains the `polish` and `llm` blocks; the eight `polish.*` methods and the three Linux `llm.*` additions answer, with fixtures. `[polish]` and `[llm]` join the schema, the default file and `config print-default`, and `polish.rules.*`, `polish.apps.set` and `llm.endpoints.trust` write through a new comment-preserving `edit::set_structured` so a hand-written file keeps its comments. Storage migration `0002-polish-notice` adds the two nullable columns. The CLI gains `dettivo polish test|rules|presets|apps` and `dettivo llm providers|endpoints|trust|test`. `docs/polish.md` is the document; ADR 0023 records the port, the provider interface and the trust gate.
