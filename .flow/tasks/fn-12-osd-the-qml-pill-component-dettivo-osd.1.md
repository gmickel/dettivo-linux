## Done summary
### Summary
Built the recording pill and its host. `Dettivo.Osd` (qt/qml/Dettivo/components/Osd.qml with OsdContent, OsdDot and OsdThread) is one 36 px pill whose `state` is listening, transcribing, enhancing, inserted, copied, error or hidden, with `level`, `title`, `hint`, `engine`, `elapsed`, `words`, `target`, `reason` and `action`; every colour, size and duration is a Theme or Motion token, every text is one line that elides, the first words are the transcript's first sentence, the hide timers (hide_after_ms for inserted and copied, error_hide_after_ms for error) live in the component and report `hidden()` on the next event-loop pass, reduced motion holds the bars and cuts the transitions, every element has an accessible role and name, and an unknown state name warns and hides. `OsdBars` (qt/qml/Dettivo/osd/osd_bars.cpp) is a C++ scene-graph item in the module: one parent node with a rectangle node per bar, a centre-weighted envelope times a deterministic per-bar drift, per-frame easing on the render thread, and it requests its next frame from updatePaintNode so the animation runs at the display rate with no timer (rectangle nodes rather than a raw geometry node because the software adaptation the offscreen renders use draws only those; the batch renderer merges them into one draw). No Canvas, no QQuickPaintedItem; scripts/lint-qml-tokens.sh now refuses both.

`dettivo-osd` (qt/apps/dettivo-osd, host pieces under qt/host/osd) decides its host at start: layer_shell on Wayland when built with layer-shell-qt and a fresh wl_registry roundtrip shows zwlr_layer_shell_v1 (overlay layer, anchors per [osd] position, margins, exclusive zone 0, no keyboard); window (frameless, always on top, no focus, positioned on X11) otherwise; disabled with a notice in osd.status.json when [osd] enabled is off, host = "layer_shell" cannot be met, or the panel plugin's bus name dev.dettivo.OmarchyPanel is on the session bus. [osd] monitor = "focused" follows Hyprland's focused output through its IPC socket, a named output falls back to the primary. Caret avoidance reads the focused window's geometry from Hyprland IPC directly (the S-08 probe is not on main, PR #10; ADR 0015 records the switch to the daemon's `insert.target` geometry once it lands): the pill takes the opposite vertical edge when the focused window reaches into its band on the configured edge and not into the opposite band. OsdModel maps the stream (dictation.state, audio.level, engine.state, job.progress) to the properties, holds Transcribing for a one-second beat so a fast engine never makes it flicker, reconnects to the daemon with 0.5 to 8 s backoff, hides on daemon loss, re-reads dictation.status on reconnect and after events.overflow, and serves show/hide/status over osd.sock beside the daemon socket (one JSON line each way). DETTIVO_E2E_OSD_STATE shows one state with the baseline's sample text and no daemon; `--render <png>` writes it headlessly; `--pacing <s>` prints the frame summary.

Daemon side: the dictation.state completion transition carries `insertion` (outcome, method, backend, target_app, reason) and `first_words` (first sentence, at most 72 characters; the only transcript text on the stream, recorded in docs/api/linux-deltas.md and typed in dettivo-proto with a round-trip test); dettivo-session gained StateChange::plain, first_words(), Inserter::backend() and the MockFile inserter that DETTIVO_MOCK_INSERT=1 (or mock mode) wires in so a drive proves the inserted path. [osd] joins the schema, DEFAULT_TOML, the print_default fixture and docs/config.md; DETTIVO_E2E_OSD_STATE joins both QA parsers and docs/qa.md. The CLI gained `dettivo osd show|hide|status` (no daemon in the path; exit 2 names dettivo-osd.service, exit 4 for a refused state) and an `osd` line in doctor. systemd/user/dettivo-osd.service (WantedBy graphical-session.target) is installed by scripts/install-user-units.sh and packaged by scripts/package.sh. The visual check is dettivo-visual-diff (qt/tools/visual-diff): both images reduce to an 18-row grid of contrast-against-background and saturation cells, the candidate stretched to the baseline's width, compared by correlation with one cell of shift tolerance; the crops under docs/design/studio/baselines/osd/ are cut from osd.png by scripts/design/crop-osd-baseline.py.
