# Linux delta register

A skill, script or MCP client written against Dettivo on macOS works against Dettivo on Linux with the same method names, tool names, resource URIs, error codes and exit codes. This register is the one place that says where Linux differs, why, and which capability flag tells a client so. Every method, resource, tool, export format and event topic in the copied contract has one disposition here, and `just lint-deltas` fails when one is missing.

## Dispositions

- **implemented**: Linux serves the item as the contract states it.
- **covered-elsewhere**: the item is served by a different route on Linux, named in the notes.
- **deferred**: not in v1; the router answers `NOT_IMPLEMENTED` and the named capability flag is `false`.
- **blocked**: cannot be served on Linux; the notes say why.
