# 0054. Delete duplicate work and keep one owner

Status: Accepted 2026-09-10

## What this gives you

Compositor dictation uses the configured mode, file transfers stay bounded, and completed setup stops doing provisioning work at every startup. Retained transcripts have one storage owner, model switches release the old model first, and diagnostics report probe failures honestly.

## Situation

The 29 historical fn-52 findings describe duplicated transport, dispatch, storage, rendering and build paths. Each claim was checked against the source after the security and correctness fixes. The existing analysis rail already scrolls above its facts. The current visual manifest already includes Home, all settings sections and Tokyo Night. Those historical claims do not require another implementation.

## Decision

- The dispatcher is the implementation inventory. Typed handlers decode each request once using the shared field-path decoder. Method availability and representative malformed-parameter diagnostics remain covered by contract tests. This closes daemon/F20.
- `dictation.toggle` owns the start-or-stop decision in the daemon. The CLI sends one operation; portal and evdev actions use the same serialized decision. Omitted start values use configuration, while explicit values and the documented MCP defaults retain their meanings. This closes agent-surfaces/F10.
- CLI, MCP and REST share the bounded Unix-socket transport and reader/writer transfer operations. Adapter-specific exit codes, guidance and HTTP statuses remain in their adapters. Requests have absolute deadlines and response-line bounds. Upload and download failures share explicit cancellation; file destinations publish only after successful completion. Qt imports read and hash bounded file chunks outside the GUI thread and size chunks against the encoded IPC envelope. Cancelling the dialog cancels its transfer or the owned meeting returned by a late import acknowledgement. These close agent-surfaces/F12 and F15 and qt-hosts/F14.
- `system.diagnostics` aggregates daemon-owned probes and preserves each result or original error. Doctor keeps local service/socket checks and its successful JSON shape, reports failures and unknown required probes, and prints concise readiness rows. This closes agent-surfaces/F14.
- Model hosts drop the old model before loading a replacement. A failed replacement leaves the host unloaded. Parakeet drops its model before resetting the process-global backend. The unused transcription dependency on the language crate is removed. These close engines/F9 and F16.
- Dictation history owns persisted transcript artifacts. Sessions no longer write a second transcript JSON file. Successful staging is discarded after archival and cancelled takes discard staging regardless of successful-take retention. An archival failure remains an explicit error with the existing bounded last-session transcript available in memory. Backends that synthesize cursor movement and deletion advertise no undo support. These close dictation/F4 and F5.
- Optional language operations run once and only when selected. Mandatory whitespace normalization preserves paragraph breaks; grammar no longer silently enables punctuation, and processor subsets no longer add unrequested editorial passes. Original macOS outputs remain identified separately in parity evidence. This closes dictation/F13 without changing configuration defaults.
- Meeting metadata retains the capture manifest rather than a duplicate database row. Transcript deletion clears transcript-bearing checkpoints and legacy metadata copies. One completion owner orders speaker assignment, analysis and retention using the policy frozen when capture or import started. Temporary audio remains until the speaker pass settles; artifact-disabled analysis does not recreate sidecars. These close meetings/F3 and F10.
- Meeting status, recovery lists, search and list rows select their required columns. SQL filters candidate statuses before decoding rows. Detail and export still load the full record. Global search ordering, stable IDs and notes survive the projection change. This closes meetings/F15.
- QA children acquire an owning process guard immediately after spawn, including before readiness checks. The profile records observations while process guards terminate and reap children. First-run fixtures use the profile's existing model tree and respect retained-profile inspection. These close qa-rig/F18 and F19.
- Automated field input waits for observed focus on an editable, enabled, focusable text field and the owned active window, bounded to two seconds. XTEST flush alone does not acknowledge Qt focus. Targeted text reads avoid unrelated delegate traversal, and History requires an observed query before submission. A recognized vanished-object error permits one immediate complete-tree reacquisition, with no partial nodes reused; a second transient error or any permanent error is reported. This repairs the pre-existing input-delivery, false-verification and import traversal defects exposed by qml/F18 and integrated QA.
- Approved-render comparison preserves image dimensions and pixel colours; the artboard structural score remains separate. Small independent regression plants test sensitivity without approving references or increasing tolerances. The complete transport replay is one library operation used by the CLI and release pack, with required result sections checked. GPU allocation and aggregate activity remain diagnostics when inference cannot be attributed to the measured engine and device. These close qa-packs/F6, F8 and F12 and qt-hosts/F15.
- Qt and Rust consume the 131 shared QA-hook conformance cases in `crates/dettivo-core/fixtures/qa_environment_cases.json`. Recognition enforces QA mode even for hooks the host does not consume; unused stored parser fields are removed. First-run provisioning runs only while required or reopened, settings models refresh when their routes need them, and diagnostics load on request. App status explicitly requests download observations from the existing catalogue; `active_downloads` remains -1 until both speech and LLM replies validate, so a dormant table cannot fabricate an idle zero. Unobserved MCP hosts and model backend facts say "not checked" rather than claiming no configuration or CPU. Observed and sampled labels are preserved. These close qt-hosts/F18 and F19.
- Styled native controls provide keyboard and accessibility interaction for navigation, segments and onboarding choices. Meeting import offers only its supported meeting target. History and Meetings use one search component with independent state and explicit accessible names. The already-bounded analysis composition remains intact. These close qml/F3, F17 and F18; qml/F13 is rejected against its existing scrolling tests.
- Just is the sole build recipe implementation. `package-bin` forwards its optional destination to both staging and packaging. The docs gate checks structural links, records, contract pins and commands; the opening-word blacklist and its planted wording failure test are removed. These close ops-and-record/F15 and F18.

## Consequences

[The Linux delta register](../api/linux-deltas.md) records changed contracts and their consumed fixtures. The task receipt records every finding's disposition, regression results and live QA evidence. qa-packs/F10 is rejected against the existing complete visual manifest and the absence of the obsolete Home comparison script.

A failed model replacement loses the previous warm model. Last-session recovery after a dictation archive failure is bounded and volatile; a later session or daemon exit can replace it. Synthesized undo remains unavailable until a backend can verify the inserted range. Historical visual differences, missing approvals and GPU attribution limitations remain visible failures or unavailable evidence.

This cleanup does not supply Gordon's fn-38 approval. Native memory and startup acceptance remain governed by [ADR 0059](0059-desktop-memory-budgets-follow-measured-reference-profiles.md) and fresh measurements after the startup changes. No renderer policy, memory threshold or approved visual baseline changes here.
