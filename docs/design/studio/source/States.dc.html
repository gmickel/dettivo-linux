rules
State sentence first, in body size and weight 600. Reason second, in muted. Action third, as a small button or a key.
Urgent colour appears only as the 8 px square and never as a background.
Every error names the process or file involved so the CLI and journal say the same thing.
Loading states show the shimmer thread and an elapsed time; nothing spins.
